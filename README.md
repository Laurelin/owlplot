# owlplot

a typescript chart engine with a typed scene graph, interactive svg rendering, and server-side svg export.

🌐 **[try the live playground](https://laurelin.github.io/owlplot/)** — charts, hover interactions, axes, colors, and legends.

[![line chart generated by owlplot](docs/chart-preview.svg)](https://laurelin.github.io/owlplot/)

## 🚀 run the playground

use node 22.12+ and npm. packages are private workspaces; run from this repository.

```sh
git clone https://github.com/Laurelin/owlplot.git
cd owlplot
npm install
npm run dev:demo
```

open the local url printed by vite. for the react playground, run `npm run dev:react`.

## 📊 supported features

📈 line charts with linear, monotone, and catmull-rom curves, point markers, and area fills.

🖱️ tooltips, legends, and hover indicators in the browser renderer.

🧩 typed scene nodes and scene transforms for custom output.

📄 svg string export for node and server rendering.

## 🚧 current limits

line charts and svg output are implemented. canvas, pdf export, and accessibility narration are future work.

svg string export omits tooltips, hover behavior, and the legend overlay. node uses approximate text metrics; browser layout can use canvas measurements. font metrics can change label placement.

## 🧪 build and check

```sh
npm run ci
npm run export:svg -- ./chart.svg
```

`ci` builds the workspaces, checks package exports, and runs the tests. the export command writes a chart without a browser.

## 🧩 example

compute a scene, then serialize it to svg:

```ts
import {
  ChartKind,
  approximateMeasureText,
  computeChartScene,
} from '@owlplot/core'
import { sceneToSvgString } from '@owlplot/renderer-svg'

const size = { width: 640, height: 360 }
const { scene } = computeChartScene(
  {
    kind: ChartKind.LINE,
    series: [{ id: 'sample', points: [{ x: 0, y: 10 }, { x: 1, y: 15 }] }],
  },
  size,
  { devicePixelRatio: 1, measureText: approximateMeasureText }
)

const svgMarkup = sceneToSvgString(scene, size)
```

the node export script bundles workspace imports with esbuild. use that runner for a complete executable example.

## 🔍 architecture and examples

core computes layout, scales, and a typed scene from chart data. the svg renderer consumes that scene. this boundary lets tests inspect chart geometry without a browser and lets browser rendering and export share the same input.
